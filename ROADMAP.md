# 🗺️ Roadmap do Projeto - API Automation Lab

Este roadmap descreve a evolução planejada para este laboratório de automação de testes de API, visando a consolidação de boas práticas de mercado (Padrão Ouro).

## 🚀 Fase 1: Fundação e Cobertura Base (Atual)
- [x] Mapeamento e estruturação de Collection no Postman.
- [x] Implementação de testes de CRUD completos (Produtos e Usuários).
- [x] Validação de cenários negativos (usuário duplicado, falha de atualização).
- [x] Validação de contratos de API via `JSON Schema`.
- [x] Execução automatizada via CLI utilizando **Newman**.
- [x] Documentação formal de Casos de Teste em Markdown.

## 📈 Fase 2: Robustez e Integração Contínua (Próximos Passos)
- [ ] Configuração de pipeline de CI/CD utilizando **GitHub Actions** para rodar a suíte automaticamente a cada push.
- [ ] Resolução e ajuste definitivo do reporter visual alternativo para exportação de métricas.
- [ ] Parametrização avançada de massa de dados dinâmica utilizando o módulo `Faker` nativo do Postman.

## 🌟 Fase 3: Escala do Laboratório
- [ ] Expansão para testes de carga e performance básicos integrados na esteira.
- [ ] Publicação de badges de status de build no README principal.
